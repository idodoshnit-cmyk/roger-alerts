# הוראות הקנייה של רוג׳ר במייל

כל יום מסחר GitHub מפעיל את `live.py` לפני פתיחת הבורסה בניו יורק. הסקריפט בודק כל 5 דקות את המניות שפתחו בגאפ של 20% ומעלה. כשרוג׳ר אומר "להיכנס", נשלח מייל עם המניה, הכניסה, הסטופ והיעד של ג׳יימס. אחר כך נשלח מייל כשהסטופ או היעד נוגעים, וסיכום בסוף.

- שעות ההוראות: 9:35 עד 11:40 שעון ניו יורק (בדרך כלל 16:35 עד 18:40 שעון ישראל).
- כללי הצוות: עד 3 עסקאות ביום, מניה אחת פעם אחת, עצירה ליום אחרי 2R-.
- מהירות: המייל יוצא כמה שניות אחרי שנר ה-5 דקות נסגר. כל מייל מראה מתי רוג׳ר החליט ומתי המייל יצא, ו-`log/alerts.csv` שומר את זמני השליחה.
- סודות (Settings → Secrets and variables → Actions): `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`, ואם רוצים לשלוח לכתובת אחרת גם `ALERT_TO`.
- בדיקה: Actions → Roger buy alerts → Run workflow שולח מייל בדיקה אחד.
- `hans.py`, `setups.py`, `roger.py` ו-`data/*_brain.json` הם עותקים מהאימון. האימון עצמו לא רץ כאן.

הבוט רק שולח מיילים. הוא לא מחובר לברוקר ולא קונה או מוכר. תרגול בלבד, חומר לימודי, לא ייעוץ השקעות.
